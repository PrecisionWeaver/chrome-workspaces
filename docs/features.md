# Features

|                           |                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| ------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Command palette**       | `⌘K` (or `Ctrl+K`), even from the terminal, opens one box that fuzzy-finds every workspace and review request and runs actions (new workspace, settings, refresh). `nw` finds _New workspace_.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| **Switch**                | `⌃⇧←` / `⌃⇧→` or click a workspace. All workspace windows share the size you last set, so switching swaps content in place.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| **Create**                | `+ New workspace` opens one view: a **Name**, the **Repo** to start in, the **Model** (`claude --model`), optional **Tabs** (one URL per line, opened with the workspace), a first message, and where it lives. Scripts can create one too, through the helper's [HTTP API](setup.md#scripting-workspaces). A window that isn't a workspace offers to become one.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| **Templates**             | **Save current…** in the New workspace view keeps its repo, model, tabs, first message and window as a named template; pick one to fill the form in a click.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| **First message**         | **Blank**, **From prompt** (pick from your notes file; `PR-URL` and `PROJ-XXX` are filled in from the PR), or **From text** (type anything). The message runs once; reopening resumes the conversation.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| **Window or group**       | **New window**, or **This window**. Joining a window that already holds a workspace gives the new one its own tab group beside it, so several terminals can share a window. Pick one from the list or by clicking a tab in its group; its badge takes the group's color. Switching collapses the window's other groups and shows the new one's; expand any by hand and it stays that way until the next switch. Merging windows into tab groups keeps their workspaces. A workspace sharing a window without a group of its own takes the unclaimed group there that holds its tabs when you switch to it.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| **From a review request** | Clicking a review request opens the same view with the PR's details above it: branches, size, review and check status, labels, the description rendered as markdown, collapsed lists of the biggest files and latest commits, and its **review comments** (open threads first, resolved ones folded; read-only, each links to GitHub where you can reply). It is named for the PR, starts in its repo, uses From prompt with `PR-URL` and `PROJ-XXX` filled in, and has the PR's URL filled into Tabs, so it opens first unless you change it. Everything else works as for any new workspace.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| **Source control**        | An accordion for the workspace in view: its branch (↑ahead ↓behind) with a **branch switcher**, a **vs main** comparison of everything the branch changes, the **CI status** of its pull request (click for GitHub), **stage, unstage and discard** per file or all at once (discard asks twice) with a **commit box** (`⌘⏎`), following Claude into any git worktree it checks out (shown as a worktree chip, with that worktree's own branch and history), what Claude is doing, staged and unstaged changes, and a commit graph like VS Code's (its graph column is capped at about eight lanes, and a long branch name is cut with an ellipsis, its tooltip has the full name). Click a file for its diff against HEAD, or a commit for its files and diffs. It refreshes every 5 seconds and whenever Claude starts or stops working, and files that just changed are highlighted, so you can watch the work as it happens.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| **Review requests**       | Open PRs requesting your review, every open PR in `watchRepos`, and your own open PRs (drafts included) in any repo in `watchRepos` or `repoDirs`, plus any PR in those repos you reviewed that has had commits pushed since (a **New commits** badge, for a review that asked for changes or commented, not one that approved). Refreshes every 5 minutes or on ↻; a gateway error from GitHub is retried, and if GitHub rate-limits the requests the list keeps its last contents and waits, a minute at first and up to fifteen, before asking again. Each carries a badge: **Draft**, **Ready for review** (open, waiting on a review), **Can merge** (approved, checks passing, no conflicts), or why it can't merge. An **Approved** badge beside it marks a PR whose latest review from you is an approval. Search by text (title, author, repo, ticket or branch name), or filter by author, repo and status, where a PR that can't merge is listed under its reason (Conflicts, Behind, Checks failing, Changes requested, Blocked). A **Checks passing**, **Checks running** or **Checks failing** tag shows the head commit's checks (none when it has no checks, and left out where **Can merge** or a _Checks failing_ reason already says it), and a green dot at the right means the PR already has a workspace. Clicking one also opens the PR in a normal tab outside your workspace's tab group, unless it's already open there. A workspace you then create for it takes that tab along, rather than opening a second copy; a PR tab that was already there stays put. |
| **Resize**                | Drag the list's right edge to widen it, and the top edge of **Source control** or **Review requests** to make them taller or shorter (double-click an edge to reset). Sizes are remembered.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| **Organize**              | With five or more workspaces a filter box appears (name, ticket, directory, or words like `waiting` and `working`). Right-click a workspace to **pin** it to the top, **archive** it (with or without closing its tabs, see below), rename it, or give it a color. The New workspace view, including from a review request, has a **Color** row too.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| **Reorder**               | Drag workspaces in the list; the shortcuts follow that order. Workspaces that share a window as tab groups stay in step with the tab strip both ways: reorder the list and the groups move, drag a group in the strip and the list follows.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| **Attention**             | The toolbar icon shows how many workspaces are waiting for input, and the list header says so too. Turn on **Desktop notifications** in Settings to be told when one starts waiting or finishes; clicking the notification switches to it.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| **Status**                | Red dot: `claude` needs input. Green: working. Reported by hooks the helper adds to each workspace's `claude`, so nothing is installed into your Claude settings.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| **Updates**               | Settings has **Check for updates**, which fetches this copy's remote and lists what the newest release (`vX.Y.Z` tag) brings; commits on `main` since that release wait for the next one. A copy with no release tags follows its upstream branch instead. **Update now** (it asks twice) fast-forwards to the release, installs dependencies if they changed, rebuilds the extension and restarts the helper, then offers **Reload extension**. It never overwrites uncommitted changes or local commits, and says why when it will not update.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| **Activity**              | Expand a session in Settings and choose **Show activity** to see what its Claude has recently done, from its transcript: what you asked, what Claude said, each command by its description, and the files it changed. It refreshes while open.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| **Plan usage**            | Settings shows how much of your Claude plan's limits are used, as `/usage` does: the current session and the current week (and a gateway's spend limit), each with a bar, the percentage used and when it resets. The figure stops at 100%, as `/usage` does. A gateway's spend limit also shows the dollars spent against it and its period, when claude reports them (Claude Code 2.1.284 or later); a Max or Pro plan has no dollar figure to show. The figures come from `claude` itself, which reports them to a workspace's status line after its first reply on a Pro or Max plan, so they are as fresh as your last message and say how old they are. Nothing is sent to Anthropic and no login is read. Only sessions started from this app report, and the app's status line runs your own (`statusLine` in `~/.claude/settings.json`) as before; a project's own `statusLine` is not run.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| **Usage and cost**        | Settings shows each session's token count with an estimated dollar cost, and a usage card across every workspace. Pick **Today**, **7 days**, **14 days** or **30 days** (remembered) and the chart, cost and tokens follow, with the change against the range before it ("↑ 23% vs the previous 7 days"), the per-day average, active days and busiest day, output and cache-read tokens, and a split by model. **Today** is drawn by hour, with the current hour marked; the other ranges are drawn by day. Days and hours are in your local time. Dollars are estimates from per-model rates (cache writes 1.25× input, reads 0.1×); correct them with `pricing` in the config, e.g. `{ "opus": { "input": 15, "output": 75 } }` per million tokens.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| **Getting started**       | Until everything is set up, Settings opens with a checklist: the helper starts at login, the extension ID matches, the config has no entries it had to ignore, the status hooks are running, `gh` is signed in, a prompts file and repo folders exist, a switch shortcut is bound, and you have a workspace. Each open step says how to fix it; **Dismiss** hides it. `npm run doctor` runs similar checks from a terminal.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| **Warnings**              | Settings lists workspaces holding a lot of memory and dev servers left listening for hours without using any CPU, with a **Stop it** for the servers, and the gear turns amber when there is something to look at. Limits are `limits.memoryWarnMb` (default 4096) and `limits.idleServerHours` (default 4) in the config.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| **Terminal**              | The `>_` button in the list header, or **Terminal** in `⌘K`, opens a plain login shell in the panel, for a command line that belongs to no workspace. It starts in your default directory. Closing the view leaves it running, so a dev server started there keeps going; reopening it brings the scrollback back, and `exit` ends it (the next open is a fresh shell). A `claude` typed into it is not a workspace, so it has no status. There is one, and it ends when the helper restarts.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| **System monitor**        | The pulse button in the list header, or **System monitor** in `⌘K`, opens `btop` in the panel (plain `top` if `btop` isn't installed: `brew install btop`). It is a terminal of its own, not a workspace, so it needs no window or tab group. Quit with `q` or **Back** and it stops; it only runs while you are looking at it.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| **Settings**              | The ⚙ in the list header opens an admin view: the helper's status with **Restart** and **Stop** (launchd-managed only) and its log. When the helper is stopped, the panel's notice has a **Start helper** button, which asks the native-messaging host to load its launchd agent; every workspace's session (ending with a Helper memory line and a total, so the figures add up: the header shows workspaces only) with the tokens its claude session has used, and the processes beneath it, their CPU, memory and listening ports, each with **Stop** / **Force** (only within that workspace's own tree) and a per-session **Restart**; housekeeping (clear uploads and the log, prune stale worktrees, refresh reviews, export the workspace list); the effective config; and checks for the `gh` login and extension ID. Destructive buttons ask twice.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| **Send to workspace**     | Right-click selected text, a link or a page and choose **Send to workspace** to paste it into that workspace's terminal. It is pasted, never submitted, and control characters are stripped. The workspace's terminal must already be open.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| **Attachments**           | Drag files onto the terminal, or paste a screenshot, and they are saved under `~/.chrome-workspaces/uploads/` (cleared after a week) with their path typed in for `claude` to read. Up to 25 MB each.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| **Sessions**              | Closing the panel leaves `claude` running; reopening reattaches with scrollback. `exit` closes the shell; the next open resumes the last conversation.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| **Rename / archive**      | Double-click a name to rename (a tab group takes the new name). **Archive** (right-click, or hover and click × twice) ends the session and leaves its tabs open. **Archive & close tabs** also closes its tab group; a window closes only when the workspace owns it outright, never one other workspaces share, and Chrome closes a window left empty. Archived workspaces sit under **Archived** (the last 50) with their pin and color; clicking one, or choosing it in `⌘K`, brings it back with its tabs and resumes its conversation. **Clear all** on the Archived header forgets every one.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| **Appearance**            | Settings has **Theme** (system, dark or light) and **Density** (comfortable or compact); the terminal's colors follow the theme. The workspace list is keyboard-friendly: Tab into it, then `↑` `↓` (or `j` `k`), `Home`, `End`, `Enter` to open, `F2` to rename.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| **Collapse**              | `‹` shrinks the list to a narrow rail.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |

**Limitations**
- Claude in Chrome picks its own window, so a workspace's `claude` may open tabs elsewhere.
- Reloading the extension closes every side panel. The switch shortcuts reopen it, as does a key bound to _Open the workspace panel_.
